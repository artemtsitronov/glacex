# Roadmap

## Vision
Glacex is an immediate-mode library with persistent state.
It's aiming to become a solid alternative to other popular libraries like egui, iced and other native GUI libraries.
It's a long and hard project, that still needs to be completed.

## Future plans
- 0.1.3: Dropdown/Select widget
- 0.1.4: Proper group selection control system, animations
- 0.1.5: Overlay system
- 0.1.6: We'll see what comes next
